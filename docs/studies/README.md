# Studies

Prior-art studies for gds. Each reads one outside tool or workflow, read-only, and says what gds should borrow and avoid. Lessons are in our own words: no copied code or assets, and quotes stay short.

- [Effekseer](./effekseer.md): an engine-neutral particle editor; node tree, parameter groups, chunked file with editor and runtime data, step migrations.
- [VFX.LAB](./vfx-lab.md): a browser tool for stylized effects; role-named layer stack, shared paths, undo as the only history.
- [Pablo's armor](./pablo-layered-vfx.md): an AI-assisted asset cut into pieces small enough for an agent, each with its own reference.
- [Layer sizing](./layer-sizing.md): the rule the VFX studio and its agents follow for how small a layer is and how it is checked.
- [Feed-forward](./feed-forward.md): notes for the vision plan on story blocks per spark and a focus minimap.
